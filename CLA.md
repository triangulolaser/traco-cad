### 6. How to agree to this CLA

Agreement happens through the normal GitHub workflow:

1. **Commit sign-off (DCO):** sign off your commits with `-s`:
   ```bash
   git commit -s -m "cad: add a new dimensioning algorithm"
   ```
   This adds to the commit message:
   `Signed-off-by: Your Name <your.email@example.com>`

2. **Pull request:** in the body of every pull request to the public Traço CAD repository,
   check the agreement box:
   - `[x] I have read and agree to the Traço CAD Contributor License Agreement (CLA.md).`
