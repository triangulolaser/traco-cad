# Glossary

Traço is the 2D CAD by Triângulo Laser, as a desktop app and in the browser.

## Language

**Drawing**:
A DWG or DXF document open in Traço, with layers, entities, dimensions and blocks.
_Avoid_: file, project

**Entity**:
An element of the drawing (line, arc, polyline, text, dimension) with its own identifier.
_Avoid_: object, item

**Original**:
The file exactly as the importer read it, kept with the tab outside the drawing.
_Avoid_: copy, backup

**Traço desktop**:
The installed app (Windows, macOS, Linux), which updates itself from the feed published by
Triângulo Laser.

**Interface language**:
Portuguese, English or Spanish, chosen in the desktop selector or from the system language;
the drawing itself does not change.
_Avoid_: drawing translation, locale

**Command**:
An action typed in the command line or triggered from the ribbon (`LINE`, `TRIM`), with its
aliases and prompts.
_Avoid_: tool, function
